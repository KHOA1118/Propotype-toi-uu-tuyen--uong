# Presentation scenario: shared real-road corridors

The default demo is generated by `RoadRouter.presentation_scenario()` from the supplied HCM OSM graph. It is not a set of screen coordinates or fabricated route geometry.

The generator chooses a central depot from the mutually reachable directed road component, then selects 24 real road nodes at 1.2–4.2 km network distance in three geographically separated areas. All candidate journeys use the depot's directed outbound road tree, creating a shared central corridor while retaining several distinct delivery areas. It assigns demand 10 to each customer and capacity 40 to each of six vehicles. Capacity therefore requires six routes with four customers each, while the original LNS engine continues to decide which customer goes in which route and in what order.

`GET /api/demo-scenario` exposes the derived scenario. It includes original latitude/longitude, the valid OSM node reference and a design audit. The frontend converts that scenario to the unchanged `/api/optimize` contract. It then requests `/api/network/routes`, which calculates geometry from real directed OSM edges.

The routing response now includes an internal `overlap` report for the optimized result:

- every OSM node and edge used by two or more vehicles;
- number and identities of affected routes/vehicles;
- most-shared OSM node; and
- an incident candidate that maximizes real route participation and then prefers a longer visible shared segment.

No traffic behavior is changed and no incident is applied.

## Validation

`python -m unittest discover -s tests` passes 46 tests. `node --test tests/test_map_frontend.cjs` passes 7 live tests when the server is running at the configured `LNS_TEST_URL`; it verifies 25 valid OSM stops, six 4-customer LNS routes, directed road geometry, real shared nodes/edges and a multi-vehicle incident candidate. The original LNS engine hash is unchanged.

Run `python server.py --port 8001`, open `http://127.0.0.1:8001`, and click **Tối ưu tuyến**. The expected scale is 24 customers, six routes, and the overlap card. This does not implement vehicle animation or congestion.
